# Cognitive modeling meets computational linguistics

This is a repository for my course 'Cognitive modeling meets computational linguistics' at the LOT 2026 Summer School in Groningen:
https://lotschool.nl/events/lot-summer-school-2026/#toggle-id-5

## Course info

- **Level:** Advanced
- **Credits:** 1 EC

### Target group

RM2 students who have previously written a paper on the topic, or PhD students whose research relates to the topic.

### Prerequisites

- Experience with cognitive modeling and/or computational linguistics or natural language processing
- Ability to program in Python
- Basic knowledge of the terminal and Git

### Course description

This course looks at computational models as tools for studying how humans learn and use language. Instead of focusing on a single linguistic domain, we draw on examples from several areas to discuss practical questions: when can a model be taken seriously as a model of cognition; what assumptions are built into its design and training data; what kinds of representations it learns; how our modeling choices affect the conclusions we draw. We will connect model outputs to behavioral and developmental evidence and gain hands-on experience with existing model implementations. Case studies span multiple levels of linguistic structure and learning scenarios: phonetics and phonology, morphology, lexical learning, syntax and sentence processing, multimodal learning, and bilingualism.
